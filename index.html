Introducción a la Fluidez Tipográfica

Publicado: 15 Nov, 2023 CSS Avanzado Intermedio

Este párrafo demuestra el cuerpo de texto fluido. Si redimensionas la ventana del navegador, notarás que el tamaño de la fuente no salta de un tamaño a otro (como pasaría con media queries tradicionales), sino que escala matemáticamente gracias a la función clamp().

¿Qué es CSS Clamp?

La función clamp() permite definir un valor que está sujeto a un límite superior e inferior, con un valor preferido que fluye entre ellos. Es perfecta para crear diseños que se adaptan fluidamente sin necesidad de múltiples media queries.

Ejemplo de Código

:root {
  /* Sistema fluido con clamp() */
  --fs-body: clamp(1rem, 0.9rem + 0.5vw, 1.25rem);
  --fs-h1: clamp(2rem, 1.5rem + 5vw, 3.5rem);
  --fs-h2: clamp(1.5rem, 1.2rem + 3vw, 2.5rem);
}
